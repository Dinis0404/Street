# 實景參考庫

存放每個街區的**實景參照照片**與**比對截圖**，供施工時逐格比對還原度。

## 收錄規則

- 目錄以街區命名：`商圈/`、`四四南村/`、`吳興街/`、`象山/`、`捷運站/` …
- 參考照片命名：`<比對點>-<方位>.jpg`（例：`村頂望101-南.jpg`、`A9外觀-西北.jpg`）
- 比對結果截圖命名：`compare-<比對點>.png`（遊戲內同角度截圖，與參考照 side-by-side 檢查）
- 每個 S 級地標至少 3 張不同角度；A 級街區至少 1 張

## 注意

照片僅供**視覺比對**（量比例、看細節），不得裁切作為貼圖素材使用（著作權考量，見 docs/開發路線圖.md §3 鐵律 5）。
